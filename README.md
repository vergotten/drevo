# 🌳 Древо — просмотр .at5 на телефоне

Мобильный просмотрщик родословных из программы **«Древо Жизни»**. Программа работает только на компьютере, а это приложение открывает её экспорт (`.at5`) прямо на телефоне — в браузере или внутри Telegram.

## Возможности

- Древо с фотографиями: предки сверху, потомки с супругами снизу
- Режим **«Весь род»** — все потомки основателя рода на одной схеме
- Список **«Роды»** — все ветви семьи с количеством человек
- Карточка человека: фото, даты и места рождения и смерти, занятие, заметки, родители, супруги, дети, братья и сёстры
- Поиск по фамилии, имени и отчеству
- Перемещение пальцем и масштабирование щипком
- Тёмная тема — автоматически, по настройкам телефона

## Приватность

Файл `.at5` **никуда не загружается**. База читается прямо на устройстве, в браузере (SQLite через [sql.js](https://github.com/sql-js/sql.js)). В этом репозитории только программа, данных семьи в нём нет.

После первого открытия файл запоминается в браузере, и выбирать его заново не нужно. Забыть его можно через меню «☰ → Забыть сохранённый файл».

## Как пользоваться

1. В «Древе Жизни» на компьютере экспортируйте базу в файл `.at5`.
2. Перекиньте файл на телефон, например через Telegram или облако, и сохраните его в память телефона.
3. Откройте приложение, нажмите **«Открыть файл .at5»** и выберите файл.

## Запуск в Telegram (Mini App)

1. В **@BotFather**: отправьте `/newbot` и создайте бота.
2. Затем `/mybots` → ваш бот → **Bot Settings → Menu Button** → отправьте ссылку на эту страницу, например `https://ЛОГИН.github.io/drevo/?v=2`.
3. В боте слева от поля ввода появится кнопка — она открывает древо.

> Если после обновления Telegram показывает старую версию, поменяйте в ссылке `?v=2` на `?v=3` и так далее.

## Размещение

Весь проект — один файл `index.html` без зависимостей, его можно положить на любой хостинг. Для GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.

## О формате .at5

`.at5` — это база данных SQLite. Основные таблицы:

| Таблица | Что хранит |
|---|---|
| `Persons` | люди (пол, ссылки на события рождения и смерти) |
| `ValuesStr` | текстовые поля: фамилия (64), девичья (65), имя (66), отчество (67), занятие (73), заметки (89) |
| `Events` + `EventDetails` | события и роли участников: рождение (ребёнок, отец, мать), брак (муж, жена), смерть |
| `ValuesDates` | даты событий |
| `Places` + `ValuesLinks` | места |
| `Documents` | фотографии (превью JPEG хранится в поле `preview`) |
| `DocumentDetails` | привязка фото к людям |

Полноразмерные оригиналы фото в `.at5` не входят — программа хранит их отдельно на компьютере. Поэтому приложение показывает встроенные превью.
